# Готовые установочные файлы Quake III Arena для Android

В этой папке находятся полностью собранные и подписанные файлы APK, готовые к установке и распространению на любые устройства Android:

## 📦 Файлы:
1. **`ioquake3-v1.0.0-release.apk`** (10 МБ) — **Основная релизная версия (Рекомендуется)**.
   - **Встроенный In-App Downloader**: при первом запуске на новом телефоне игра сама скачивает и распаковывает все нужные `.pk3` файлы (`baseq3`, `osp`, `excessiveplus`) с высокой скоростью.
   - **Импорт локального ZIP (SAF)**: если на телефоне уже есть скачанный архив `q3_resources.zip`, можно просто нажать кнопку «Выбрать ZIP из памяти» через стандартный системный проводник Android (без root и без ADB!).
   - **Мгновенный запуск**: при наличии файлов игра стартует сразу без задержек.
   - Оптимизирована компилятором, подписана стандартным v2-ключом.
   - Включает все наши фиксы: идеальный круглый прицел 1:1, оригинальная иконка Quake 3, автоскрытие HUD при подключении периферии, защита от краша при подключении док-станций.
   - Поддерживает архитектуры **`arm64-v8a`** (все современные смартфоны и планшеты) и **`x86_64`** (эмуляторы).

2. **`ioquake3-v1.0.0-debug.apk`** (19 МБ) — **Отладочная версия** (с подробными логами `logcat`).

3. **`q3_resources.zip`** (542 МБ) — Полный эталонный архив игровых ресурсов:
   - `baseq3` (`pak0.pk3` – `pak8.pk3`)
   - `osp` (`zz-osp-pak0.pk3` – `zz-osp-pak3.pk3`)
   - `excessiveplus` (`z-xp-2_0a.pk3` – `z-xp-2_3.pk3`)

4. **`install_to_device.sh`** — Скрипт автоматической установки в 1 клик через USB/Wi-Fi ADB.
